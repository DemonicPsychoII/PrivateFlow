# Reporting a vulnerability

Please report security vulnerabilities privately through GitHub's
[private vulnerability reporting](https://github.com/DemonicPsychoII/PrivateFlow/security/advisories/new).
Include the affected version, impact and steps to reproduce, using synthetic
data rather than private recordings, transcripts or credentials.

Please avoid public issues for undisclosed vulnerabilities. This personal
project has no guaranteed response time or supported-version policy.
